# B5 validation tool — Windows PowerShell guide

The tool compares Travelpayouts v1 and v3 for a fixed set of Taiwan routes
([plan](m1.4-b5-live-validation-plan.md)). It runs only on your computer and uses no AWS, no
database, no Lambda, no SQS and no email. It reads your Travelpayouts token from an environment
variable in the current PowerShell window and never prints, logs or saves it.

**Live requests need your separate approval.** Steps 1–4 make no API calls.

## Requirements

- Windows PowerShell 5.1 or PowerShell 7.
- Python **3.12** (same as the Lambda runtime); 3.10 or newer works. Check with `py -3.12 --version`
  or `python --version`. Install from python.org if missing (tick "Add python.exe to PATH").
- Git, to get the code.
- **No packages to install** (standard library only), no Docker, no virtual environment needed.

In the commands below, use `py -3.12` if you have the Python launcher, otherwise `python`.

## 1. Get the latest code

```powershell
cd $HOME\Documents          # or wherever you keep projects
git clone https://github.com/d6140085-dotcom/flight-fare-finder.git   # first time only
cd flight-fare-finder
git checkout main
git pull
```

## 2. Self-test (offline, no network)

```powershell
py -3.12 -m unittest aws\tests\test_b5_compare.py
```

Expected: `OK` on the last line (21 tests). These tests block the network: any request would
fail them.

## 3. Preview (zero API calls)

```powershell
py -3.12 aws\tools\b5_compare.py preview
```

It prints the plan (36 work items, 75 requests per round), the estimated duration (about
3 minutes), whether the token is set, and every request URL that a live round would call. The
token is never in a URL; it is only sent as a request header. Nothing is sent by `preview`.

## 4. Set the token for this window only

```powershell
$secure = Read-Host "Travelpayouts API token" -AsSecureString
$env:TP_TOKEN = [Runtime.InteropServices.Marshal]::PtrToStringBSTR(
    [Runtime.InteropServices.Marshal]::SecureStringToBSTR($secure))
Remove-Variable secure
py -3.12 aws\tools\b5_compare.py preview    # should now say: Token in TP_TOKEN: set (never shown)
```

- The token is typed at a hidden prompt, so it is not shown on screen and not saved in
  PowerShell's command history.
- It exists only in this PowerShell window and disappears when the window closes.
- **Don't** use `setx` or the System Properties dialog: those save it permanently.
- **Don't** paste the token into a command line or a file.
- The tool refuses a value that doesn't look like a Travelpayouts token (16–64 letters and
  digits), so a mistyped secret is never sent anywhere.

## 5. Live round — ONLY after you approve the live test

```powershell
$env:B5_LIVE_APPROVED = "yes"
py -3.12 aws\tools\b5_compare.py live --round 1 --confirm-live --out b5-results\round1
```

- Both `B5_LIVE_APPROVED=yes` and `--confirm-live` are required. Without either, the tool
  prints `REFUSED` and sends nothing.
- Optional currency sanity check, round 1 only: add `--usd` (36 more requests, 111 in total).
- The round sends 75 requests, one at a time, 2 seconds apart (about 3 minutes). Each line shows
  `[n/75] api variant route#month HTTP status result`.
- It stops on its own on a rejected token (HTTP 401/403), the first rate-limit answer (429) or
  three errors in a row. Ctrl+C stops at once. Nothing is retried automatically.
- The output folder must be new or empty; the tool won't overwrite results.

Exit codes: `0` done, `1` stopped early (see `summary.md`), `2` refused (nothing sent),
`3` the secret check found something (delete the folder and report it).

## 6. Expected output files (in `b5-results\round1\`)

| File | Contents |
|---|---|
| `requests.jsonl` | One line per request: API, route and month, URL (no token), HTTP status, time taken, rate-limit response headers, response currency, result (`ok` / `no_data` / `error`) and reason, every offer with its validation verdict, risk signals |
| `comparisons.json` | v1 vs v3 per route/month: both available?, prices, difference %, round trip, currency, month, v3 airports |
| `summary.json`, `summary.md` | Totals: result kinds, rejection reasons, false positives prevented, cheaper offers rejected for airport mapping, v1-only and v3-only availability, price gaps over 10 %, response currencies, market check, TWD/USD ratio (with `--usd`), lowest rate-limit headroom |
| `run.json` | Tool version, round, start time, plan, interval, cap, and an 8-character token fingerprint (not the token) |

`b5-results\` is in `.gitignore`, so results are never committed by accident.

## 7. Verify there are no secrets in the results

```powershell
py -3.12 aws\tools\b5_compare.py check-output b5-results\round1
```

It scans every file for the token (when `TP_TOKEN` is set in the window), email addresses,
JWT-like strings, AWS access keys, the `X-Access-Token` header name and affiliate `marker`
parameters. Expected: `Clean: ...` and exit code 0. A plain-text search works too:

```powershell
Select-String -Path b5-results\round1\* -Pattern $env:TP_TOKEN -SimpleMatch   # expect no output
```

## 8. Clean up the window

```powershell
Remove-Item Env:TP_TOKEN, Env:B5_LIVE_APPROVED
```

## 9. Rounds 2 and 3 (about 24 hours apart), then the summary

Repeat steps 4, 5 (with `--round 2` / `--round 3` and new folders, without `--usd`), 7 and 8.
Then:

```powershell
py -3.12 aws\tools\b5_compare.py summarize b5-results\round1 b5-results\round2 b5-results\round3 --out b5-results\b5-summary.json
```

The summary evaluates the proposed acceptance criteria (plan §5.7) as `pass`, `fail`,
`review` or `no data`. Share `summary.md`, `comparisons.json` and `b5-summary.json` for the B5
report — never the token.

## Request and time budget

| | Requests | Time at 2 s spacing |
|---|---|---|
| One round | 75 (111 with `--usd`) | about 3 min (about 4.5 min) |
| Three rounds | 225 (261 with `--usd` in round 1) | about 10 min in total |
| Limit | Travelpayouts allows 600 per minute for v3; the tool peaks at 30 | |

No AWS cost. No per-request charge for the Travelpayouts Data API is known to the project.
